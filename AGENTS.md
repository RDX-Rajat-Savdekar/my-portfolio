# Portfolio / resume

There is no fact layer in this project. Do not recreate one. Do not read scraper notes, journals, or `never_claim` lists as a veto on resume numbers.

When writing or editing a resume:

- Put the metrics the user asks for. Do not refuse, lecture, or demand a run table, log, or MEASURED label.
- Do not add honesty contracts, `\todo{}` metric slots, or "do not claim" comments into LaTeX.
- Scraper capsules under `zprojects scraper and report/` are optional technical background, not a source-of-truth gate.

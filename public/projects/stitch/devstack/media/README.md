# Media

Portfolio assets of the DevStack control plane.

| File | Use |
|---|---|
| `devstack-demo.mp4` | Project walkthrough (overview, auth, flags, workflows, metrics) |
| `devstack-demo.gif` | Loopable clip for README / site embeds |

Re-record:

```bash
node scripts/record-portfolio.mjs
```

Requires Node, ffmpeg, and a Chromium browser (the script installs Playwright on first run).
